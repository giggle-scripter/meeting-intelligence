# Meeting Intelligence Feasibility

## Objective

Prove that:

1. AI can transform a meeting transcript into a summary and structured tasks.
2. Power Automate can process the structured AI result.
3. Proposed tasks can be displayed in a SharePoint/SP365-compatible list.

## Current Scope

- Anonymized sample transcripts
- AI Builder prompt evaluation
- Structured JSON output
- Power Automate manual-flow prototype
- Microsoft Lists task demo

## Out of Scope

- Live meeting recording and speech-to-text
- Production deployment
- Final SP365 API integration
- Automatic task approval

## Current Status

- Prompt feasibility: 3/3 test cases passed
- Power Automate prototype: in progress
- External Python API: fallback spike
