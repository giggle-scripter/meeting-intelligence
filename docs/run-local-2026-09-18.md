## Optional OpenAI fallback

OpenAI is optional and only handles selected ambiguous windows. Set the key in
the current process; never put it in source, a request body, or Git. The model
and timeout below match the repository defaults. This command also clears the
Power Automate shared key, so local requests do not need an `X-API-Key` header:

```powershell
Remove-Item Env:POWER_AUTOMATE_API_KEY -ErrorAction SilentlyContinue
$env:OPENAI_API_KEY = '<paste-secret-in-this-session>'
$env:OPENAI_MODEL = 'gpt-5-mini'
$env:OPENAI_REASONING_EFFORT = 'medium'
$env:AI_TIMEOUT_SECONDS = '3600'
uvicorn backend.app.main:app --host 127.0.0.1 --port 8010
```

With the server running, the same safe fixture verifies the route and response
shape without requiring an ambiguous window, so it should make zero provider
calls even though the optional client is enabled:

```powershell
$path = 'data\power_automate_uploads\W1-SHORT-C1-N0-IT-DASG-ABS-002.txt'
$response = Invoke-RestMethod -Method Post `
  -Uri 'http://127.0.0.1:8010/api/v1/meetings/process-file' `
  -ContentType 'application/octet-stream' `
  -InFile $path `
  -Headers @{ 'X-File-Name' = [IO.Path]::GetFileName($path) }
if ($response.tasks.Count -lt 1) { throw 'Expected at least one task.' }
if ($null -eq $response.diagnostics.ai_provider_enabled) { throw 'Missing provider diagnostic.' }
$response | Select-Object meeting_title, tasks, diagnostics | ConvertTo-Json -Depth 8
```

If `POWER_AUTOMATE_API_KEY` is intentionally kept instead, send it only as a
request header and never print it:

```powershell
$headers = @{ 'X-File-Name' = [IO.Path]::GetFileName($path); 'X-API-Key' = $env:POWER_AUTOMATE_API_KEY }
$response = Invoke-RestMethod -Method Post -Uri 'http://127.0.0.1:8010/api/v1/meetings/process-file' -ContentType 'application/octet-stream' -InFile $path -Headers $headers
```

For a transcript that actually contains an unresolved candidate window, the
response diagnostics report `ai_provider_call_count` and fallback route. Use
the job API for long transcripts:

```powershell
$path = 'data\power_automate_uploads\W1-SHORT-C1-N0-IT-DASG-ABS-002.txt'
$headers = @{ 'X-File-Name' = [IO.Path]::GetFileName($path) }
$job = Invoke-RestMethod -Method Post `
  -Uri 'http://127.0.0.1:8010/api/v1/meetings/jobs/process-file' `
  -ContentType 'application/octet-stream' -InFile $path -Headers $headers
$job | ConvertTo-Json -Depth 5
```

Poll the returned `status_url` until `status` is `succeeded` or `failed`. A
server restart clears the local in-memory job store. Provider use can incur
cost and sends only the bounded fallback context described in the API policy.

## DeepSeek PAT path (separate from production)

The existing DeepSeek PAT is used only by the private data generator and V5
teacher/canary experiments. It is not a production backend provider and must
not be substituted for `OPENAI_API_KEY`. Dry-run, validation, and materialize
commands are provider-free. During this release freeze, do not execute data
generation. If a separately authorized future run needs the existing PAT, load
it without printing the value and keep it distinct from the backend OpenAI key:

```powershell
$deepSeekKeyPath = 'C:\Users\bpscm\.deepseek\api_key.txt'
if (-not (Test-Path -LiteralPath $deepSeekKeyPath)) { throw "Missing DeepSeek PAT file." }
$deepSeekKey = (Get-Content -LiteralPath $deepSeekKeyPath -Raw).Trim()
if ([string]::IsNullOrWhiteSpace($deepSeekKey)) { throw "DeepSeek PAT file is empty." }
$env:DEEPSEEK_API_KEY = $deepSeekKey
Remove-Variable deepSeekKey -ErrorAction SilentlyContinue
# Do not print the key and do not run --execute during this freeze.
```

The provider-gated execute command, for a separately authorized future run, is:

```powershell
.\.venv\Scripts\python.exe scripts\deepseek_case_generator.py `
  --execute `
  --output-dir evaluation\runtime\deepseek-cases `
  --concurrency 4 `
  --max-retries 2
```

Execute only when a separate data-generation/canary run is explicitly
authorized after the freeze. For a provider-free check, use the documented `--dry-run` or
`--validate-only` commands in `docs/deepseek-case-generator.md`. Never point
this generator at `data\validation`, `final`, or `outer` paths.

## Health and safe response checks

With Uvicorn running, these read-only checks confirm liveness and the response
contract:

```powershell
Invoke-RestMethod 'http://127.0.0.1:8010/health' | ConvertTo-Json
```

The process-file response contains `meeting_title`, `summary`, `tasks`,
`diagnostics`, and `unresolved_window_ids`. For long transcripts, submit to
`/api/v1/meetings/jobs/process-file` and poll
`/api/v1/meetings/jobs/{job_id}` instead of holding a synchronous request.
